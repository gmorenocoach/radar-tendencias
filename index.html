Fuente: YouTube Data API v3 (consulta no personalizada). "Interacción" = (likes + comentarios) / vistas; CTR y retención no son públicos para canales ajenos. "Viral" = vistas ≥ N× suscriptores del canal y ≥ 3× la mediana reciente del canal. Score = ratio × log10(1 + vistas/día).
